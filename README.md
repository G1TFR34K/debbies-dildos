# Debbie's Dildos — Age-Gate Demo

A responsive, standalone age-confirmation screen built with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Behaviour

- **I'm over the age of 18** displays a demo-only confirmation.
- **I'm not over the age of 18** displays an access-denied message.

This is only a visual self-attestation demo. The buttons do not verify a visitor's actual age, and the project does not include a store or product pages.
